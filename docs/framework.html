02 / DAILY TRACE

equity_curve.csv

  • 日期与训练 / 测试分段
  • 收盘价、信号和实际仓位
  • 仓位变化与净收益
  • 逐日组合净值
03 / AUDIT TRAIL

state.json

按时间还原运行路径，确认没有跳过阶段。

  • 当前终态
  • 状态转换历史
  • UTC 时间与阶段说明
  • 失败时另有 error.json
如何理解结果训练 / 测试按时间先后以 70% / 30% 切分，不随机打乱；指标按日频和 252 个年化交易日计算。自带 prices.csv 是合成数据，不是真实行情。单次样本外改善不代表稳定超额收益，所有结果仅供研究，不构成投资建议。
